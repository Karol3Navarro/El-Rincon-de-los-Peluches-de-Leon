# 🧸 El Rincón de los Peluches de León

Aplicación web desarrollada para un emprendimiento de venta de peluches, orientada a la visualización de productos y a la administración del catálogo.

## 🌐 Demo

**Aplicación publicada:** [El Rincón de los Peluches de León](https://el-rincon-de-los-peluches-de-leon.onrender.com)

## 📌 Descripción del proyecto

El Rincón de los Peluches de León es un proyecto personal desarrollado con Python y Django. Permite mostrar un catálogo de peluches y gestionar la información de los productos y sus categorías mediante funcionalidades administrativas.

El proyecto busca aplicar conocimientos de desarrollo web en una solución práctica para un emprendimiento, desde la implementación de funcionalidades hasta su publicación en una plataforma de alojamiento web.

## ✨ Funcionalidades

- Visualización del catálogo de peluches.
- Administración de productos.
- Gestión de categorías.
- Almacenamiento y gestión de información mediante una base de datos SQLite.
- Publicación de la aplicación web en Render.

## 🛠️ Tecnologías utilizadas

- **Backend:** Python, Django.
- **Frontend:** HTML, CSS.
- **Base de datos:** SQLite.
- **Despliegue:** Render.
- **Control de versiones:** Git y GitHub.

## 🚀 Ejecución en entorno local

### Requisitos previos

- Python.
- Git.

### 1. Clonar el repositorio

```bash
git clone https://github.com/Karol3Navarro/El-Rincon-de-los-Peluches-de-Leon.git
cd El-Rincon-de-los-Peluches-de-Leon
```

### 2. Crear y activar un entorno virtual

```bash
python -m venv venv
```

En Windows:

```bash
venv\Scripts\activate
```

En Linux o macOS:

```bash
source venv/bin/activate
```

### 3. Instalar las dependencias

Si el repositorio incluye `requirements.txt`, ejecuta:

```bash
pip install -r requirements.txt
```

### 4. Aplicar las migraciones

```bash
python manage.py migrate
```

### 5. Iniciar el servidor

```bash
python manage.py runserver
```

Abre http://127.0.0.1:8000/ en el navegador para acceder a la aplicación local.

> **Nota:** los pasos pueden requerir ajustes según los archivos de configuración y las dependencias actuales del proyecto.
